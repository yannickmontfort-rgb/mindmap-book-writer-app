# 📚 MindMap Book Writer

Logiciel d'écriture de livre basé sur une carte mentale : organisez vos parties, chapitres et scènes visuellement, puis rédigez directement dans l'application.

## ✨ Fonctionnalités

- 🗺️ **Carte mentale** interactive pour structurer votre livre (glisser-déposer, renommage rapide)
- 📚 **Multi-livres** : romans, nouvelles, poésie, manuels pratiques, mémoires — chacun avec sa structure adaptée
- ✍️ Éditeur Markdown avec aperçu, objectifs de mots, minuteur Pomodoro, mode plein écran sans distraction
- 🏷️ Fiches de référence (personnages, lieux, sources...) liées aux scènes
- 🕐 Historique des versions par scène
- 📤 Export **Markdown**, **DOCX**, **PDF**, et **PDF prêt pour Amazon KDP** (format 6x9", sommaire cliquable)
- 💾 Sauvegarde automatique, aucune perte de texte
